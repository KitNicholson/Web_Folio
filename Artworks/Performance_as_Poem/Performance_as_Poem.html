PERFORMANCE AS POEM

An attempt to make concrete poetry, by feeding live midi data from a keyboard into code that would visualise it according to a set of rules. I had a specific goal to present a musical performance in a way that it could be read like text, in a single continuous line from left to right, top to bottom. As compelling as I find this idea, it strictly limited the possible visual outcomes. Leaving much more space to explore concrete poetry produced through alternate rule sets.
