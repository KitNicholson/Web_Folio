TREACHERY OF TRANSLATION

This project touched on many large ideas but kept getting distracted from them by them by chasing a visual outcome. It was an attempt to compare computer process to human thinking, centering around a piece of code made to loosely 'mimic' human thought patterns. Using music as an expression of a human 'thought', the code would interpret it in visuals. On top of this process the code would recombine fragments of the original 'thought' into new 'ideas' that could be presented back and performed as experimental music by a human. This creates a looping process, a human plays some music, then the code interprets this with a visual output, Then a human interprets the machines output, which can be fed back into the machine to make new outputs, and so on, and so on. The treachery involved is that the machine has no brain at all. The imagery my code produces is either dominated by the sound file used, or the process of random outcomes. There is tension in my final work between what it represents and what it actually is. It represents a machine that thinks, what it actually does is translate sound into pretty pictures.
